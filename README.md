# Basic Chatbot 🤖

## Description
This is a simple rule-based chatbot developed using Python.

The chatbot responds to predefined user inputs such as:
- hello
- how are you
- bye

## Features
- Greets the user
- Replies to common questions
- Ends the conversation when the user types "bye"

## Technologies Used
- Python
- Functions
- if-elif statements
- while loop
- Input and Output

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run:

```bash
python chatbot.py
```
